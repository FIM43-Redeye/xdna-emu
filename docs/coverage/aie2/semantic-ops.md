# Semantic op ledger (AIE2)

Generated by `cargo run -p xdna-archspec --example gen_coverage_artifacts`. Do not hand-edit.

verification verdict. An op's verdict is the worst over its variants.
"Claimed by" names the override unit that set the verdict (evidence below);
`-` means the category default from `coverage/derive.rs`. Config-mode
variants are `mac(amode,bmode,variant,<x sign><y sign>)` (s = signed) or
`acc(amode,bmode,variant)`, followed by their `aiev2_vmult.h` family.

### aie2.vector_ops.verified

Vector differential fuzzer (#112/#114) vs real NPU1, re-derived per variant on 2026-10-29: the corpus's 28 live seeds (seed_* directories; the 45 in archive/ are pre-pool banks and not evidence) were replayed on the emulator with the variant-keyed fuzz recorder: all 28 match the banked silicon output, 0 diverge, 0 error (3/28 before wide vshift and the fp32 accumulator adder were derived from silicon). The 39 listed (op, variant) nodes are the integer Vector-category keys the matching seeds executed (67 distinct keys in all; the rest are non-Vector ops, Shuffle, keys the lane goldens own, or bf16 keys the fuzzer's bf16-rounded NaN-equal compare cannot discriminate). Fused compare-select lowering: min/max/abs/neg/maxdiff execute as MaxLt/MinGe/AbsGtz/NegLtz/MaxDiffLt (Min/Max are dead); pack16 and unpack32 lower to Srs/Ups. Earlier op-level history: #126 (20 ops from the executed-op audit, xdna-emu-priv: research/findings/2026-06-12-vector-semanticop-empirical-audit.md) and #127 (Pack/Unpack re-fuzzed on real NPU1, 60/60 HW match), re-confirmed per variant by the current replay. ### aie2.intrinsic_catchall.accepted

SemanticOp::Intrinsic(_) catch-all: never constructed by the live pipeline (every intrinsic-backed instruction resolves to a concrete SemanticOp at build time via semantic_from_intrinsic; the ISA build asserts 100% semantic coverage; the runtime from_intrinsic classifier is dead code). Fail-loud: the surface probe classes Intrinsic(_) as Absent -> hard ExecuteResult::Error, never a wrong value. The concrete ops it resolves to (Srs/Ups/Pack/Convert/Mac/MatMul) are model-differential checked bit-exact (#103 Half A). Accepted as unconstructible + fail-loud, not understood; silicon verification of the resolved ops is Half B (perishable queue).
